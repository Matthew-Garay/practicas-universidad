# Arquitectura - Analisis Exploratorio del CPS 1985

## Visión general

Analisis exploratorio de datos (EDA) de los salarios por hora del Current Population Survey (CPS) de 1985, con transformacion logaritmica y visualizacion en R base.

## Decisiones de arquitectura

### ADR-001: Analisis exploratorio con R base

**Estado:** Aceptado  
**Contexto:** Se requiere estudiar la forma, asimetria y comportamiento de una distribucion salarial.  
**Decisión:** Usar R base para el analisis estadístico descriptivo y visualización.  
**Consecuencias:** Análisis descriptivo completo, sin dependencias externas além de R base.

## Tecnologías

- R 4.x
