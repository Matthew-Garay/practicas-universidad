# Guia de Instalacion - Analisis Exploratorio del CPS 1985

Esta guia te ayuda a ejecutar el proyecto en tu entorno local.

## Requisitos previos

- R 4.x

## Instalacion

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Matthew-Garay/Analisisexploratorio.git
   cd Analisisexploratorio
   ```
2. Ejecuta el script:
   ```bash
   Rscript Practica8.R
   ```

## Verificacion

El script construye y refina progresivamente el histograma de la distribucion salarial del CPS 1985.
