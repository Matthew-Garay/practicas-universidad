# Prácticas universitarias

Prácticas de Inteligencia Artificial (Prolog) y Analítica de Datos (R) de la carrera de Ingeniería en Sistemas Computacionales. Cada carpeta es una práctica independiente con su código, datos, reporte en PDF y README propio.

## Prolog: Inteligencia Artificial

| Práctica | Descripción |
| :--- | :--- |
| [laberinto-72-estados](prolog/laberinto-72-estados) | Laberinto de 72 estados resuelto con búsqueda en profundidad (DFS) |
| [ciudades-gui](prolog/ciudades-gui) | Problema de las ciudades con interfaz gráfica (XPCE) y búsqueda de costo uniforme |
| [paradoja-de-dios](prolog/paradoja-de-dios) | Paradoja de Dios (paradoja del barbero) con listas, member y append |
| [problema-de-las-casas](prolog/problema-de-las-casas) | Acertijo de las casas resuelto como problema de satisfacción de restricciones |

## R: Analítica de datos

| Práctica | Descripción |
| :--- | :--- |
| [analisis-exploratorio](r/analisis-exploratorio) | Análisis exploratorio y transformación del dataset CPS1985 |
| [figuras-de-regresion](r/figuras-de-regresion) | Gráficos de regresión lineal con ggplot2 sobre el dataset airquality |
| [modelos-de-regresion](r/modelos-de-regresion) | Comparación de árbol de decisión (RPART) y Random Forest |
| [incendios-forestales](r/incendios-forestales) | Analítica de incendios forestales con algoritmos de machine learning |

## Cómo ejecutar

- **Prolog:** instalar [SWI-Prolog](https://www.swi-prolog.org/), abrir la carpeta de la práctica y ejecutar `swipl <archivo>.pl`.
- **R:** instalar [R](https://www.r-project.org/) (y opcionalmente RStudio), abrir la carpeta de la práctica y ejecutar el script `.R`.

Las instrucciones detalladas están en el README de cada práctica.
